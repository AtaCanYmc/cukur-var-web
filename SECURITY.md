# Security Policy

## Supported Versions

Şu anda projenin güncel sürümü desteklenmekte ve düzenli olarak güvenlik güncellemeleri almaktadır.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

ÇukurVar sivil bir teknoloji (civic tech) inisiyatifi olduğundan, güvenlik bizim için büyük önem taşımaktadır. Ancak her açık kaynaklı projede olduğu gibi, bizim de gözden kaçırdığımız durumlar olabilir.

Eğer sistemde herhangi bir güvenlik açığı bulduğunuzu düşünüyorsanız, lütfen **halka açık bir Issue açmak yerine** bizimle doğrudan iletişime geçin. Bu, sorunu kötü niyetli kişiler öğrenmeden önce çözebilmemiz için bize zaman kazandıracaktır.

Güvenlik açıklarını bildirmek için lütfen şu adrese e-posta gönderin:
**info@cukurvar.com.tr**

Raporunuza şu bilgileri eklemenizi rica ederiz:
* Sorunun detayı ve türü (örn. XSS, veri sızıntısı vs.)
* Sorunu yeniden oluşturmak için (varsa) adımlar
* Olası etkileri hakkında değerlendirmeniz

Bildiriminizden sonra en kısa sürede (genellikle 48 saat içinde) sizinle iletişime geçeceğiz. Katkılarınız için şimdiden teşekkür ederiz!
